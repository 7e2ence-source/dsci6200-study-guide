    一、统计学基础¶

    1. 什么是 p 值？它不是什么？〔基础 · 通用必考〕

    p 值 = 在零假设 H₀ 为真的前提下，观察到当前数据（或更极端）的概率，即 P(数据|H₀)。它不是"零假设为真的概率"，也不是"结论出错的概率"。p 小只说明"数据在 H₀ 下很罕见"，于是我们倾向拒绝 H₀。

    2. 第一类错误和第二类错误分别是什么？〔基础 · 通用必考〕

    第一类错误（I 型）：H₀ 为真却拒绝了它（"冤枉好人"，概率 = α，通常 0.05）。第二类错误（II 型）：H₀ 为假却没拒绝（"放过坏人"，概率 = β）。功效 power = 1 − β，即正确拒绝 H₀ 的概率。

    3. 什么是效应量？为什么只看 p 值不够？〔进阶 · 数据分析岗〕

    效应量是效应"有多大"的度量（如 Cohen's d）。p 值只告诉你"效应是否可能为零"，不告诉你"效应多大"。样本极大时，再小的效应也显著，所以必须同时报告效应量。

    4. 中心极限定理（CLT）是什么？〔基础 · 数据分析岗〕

    无论总体分布是什么形态，只要样本量足够大，样本均值的抽样分布就会趋近正态分布，均值逼近总体均值。这是很多统计推断的理论基础。

    5. 频率学派和贝叶斯学派的核心区别？〔进阶 · 数据科学岗〕

    频率学派把概率看作"长期重复下的频率"，参数是固定未知的，靠 p 值做假设检验。贝叶斯学派把概率看作"信念程度"，参数是随机变量，用先验 + 数据更新出后验（贝叶斯定理）。

    6. 贝叶斯定理是什么？先验/似然/后验各是什么？〔基础 · 数据科学岗〕

    贝叶斯定理：P(假设|数据) = P(数据|假设)·P(假设) / P(数据)。先验 = 看到数据前对假设的信念（如发病率 1%）；似然 = 假设为真时数据的概率（如敏感度 99%）；后验 = 看到数据后更新的信念。

    7. 什么是假设检验？零假设 H₀ 是什么？〔入门 · 通用必考〕

    假设检验是先假定一个"无效应"的零假设 H₀，再计算数据在 H₀ 下的罕见程度（p 值），若足够罕见就拒绝 H₀。H₀ 通常是"无差异、无效果、纯随机"，是"默认待证伪"的命题。

    8. 什么是置信区间？〔基础 · 数据分析岗〕

    置信区间是在给定置信水平（如 95%）下，对总体参数的区间估计。95% 置信区间的意思是：若重复抽样很多次，约 95% 的区间会包含真实参数。它比单个点估计更能体现不确定性。

    9. 相关和因果有什么区别？〔基础 · 数据分析岗〕

    相关只是两个变量一起变（可正可负），因果是指一个导致另一个。有相关未必有因果（可能有混淆变量、反向因果或纯巧合）。"冰激凌销量和溺水人数相关"是因为共同因素——夏天。

    10. 大数定律是什么？〔入门 · 通用必考〕

    样本量越大，样本均值越接近总体期望。这就是"随机森林里 800 人猜牛重取平均最准"的原理——个体误差被平均掉。

    二、机器学习基础¶

    11. 监督学习和无监督学习有什么区别？〔入门 · 通用必考〕

    监督学习有标签 y（如分类、回归），目标是学 X→y 的映射。无监督学习没有标签（如聚类、降维），目标是发现数据内部结构。半监督/强化学习是延伸。

    12. 什么是过拟合和欠拟合？怎么解决？〔基础 · 通用必考〕

    过拟合 = 训练集表现好、测试集差（模型背下了噪声）；欠拟合 = 训练集就差（模型太简单）。过拟合解决：加正则化、更多数据、交叉验证、降低模型复杂度、集成；欠拟合解决：加特征、用更复杂模型、减少正则化。

    13. 什么是偏差-方差权衡？〔进阶 · 大厂算法岗〕

    偏差 = 因模型过简导致的系统性误差（欠拟合）；方差 = 因对训练数据敏感导致的波动（过拟合）。总误差 ≈ 偏差² + 方差 + 噪声，两者此消彼长，要找平衡点。

    14. 训练集、验证集、测试集分别干什么？〔基础 · 通用必考〕

    训练集：拟合模型参数。验证集：调超参数、选模型。测试集：最终评估，只准用一次，绝不能参与训练或调参，否则评估失真（数据泄露）。

    15. 什么是交叉验证？为什么用它？〔基础 · 大厂算法岗〕

    把数据分成 k 份，轮流用 k−1 份训练、1 份验证，重复 k 次取平均。它让每份数据都被验证过，评估更稳定，能防止"碰巧一次切分导致的乐观估计"。

    16. 什么是特征工程？〔基础 · 大厂算法岗〕

    对原始数据做转换，构造更有信息量的输入特征（如分桶、交互、归一化、编码、聚合）。"数据和特征决定了模型上限，算法只是逼近这个上限"。

    17. 什么是正则化？L1 和 L2 的区别？〔基础 · 大厂算法岗〕

    正则化是在损失函数里加惩罚项防止过拟合。L1（LASSO）加系数绝对值之和，能把系数压到 0，做特征选择；L2（Ridge）加系数平方和，让系数收缩但不为 0，缓解共线。

    18. 什么是数据泄露（data leakage）？〔进阶 · 大厂算法岗〕

    模型在训练时"偷看"了不该知道的信息（如测试集标签、未来数据），导致离线评估虚高、上线失效。典型例子：先用全量数据做标准化再切分、把目标变量相关特征泄漏进训练集。

    三、回归（对应第 2 周）¶

    19. 线性回归（OLS）有哪些假设？〔基础 · 数据分析岗〕

    线性关系、误差独立、同方差、误差正态（用于推断）、自变量之间无完全多重共线性。违反会影响系数估计的稳定性和显著性检验。

    20. 什么是多重共线性？怎么检测和解决？〔进阶 · 数据分析岗〕

    预测变量之间强相关，导致系数估计不稳定（符号乱跳、标准误放大）。检测：VIF（方差膨胀因子，>10 提示有问题）、相关矩阵。解决：删变量、正则化（Ridge/Elastic Net）、PCA 降维。

    21. Lasso 和 Ridge 的区别？〔基础 · 大厂算法岗〕

    Lasso（L1）能把系数压成 0，自动做特征选择，但共线时只随机留一个；Ridge（L2）系数收缩但不会为 0，能处理共线但删不掉变量。两者合起来就是弹性网络。

    22. 什么是弹性网络（Elastic Net）？〔进阶 · 大厂算法岗〕

    损失函数同时加 L1 和 L2 惩罚（加权平均）。兼顾 Lasso 的特征选择和 Ridge 的共线稳定性，高维（p>n）数据下尤其好用。

    23. R² 和调整 R² 有什么区别？〔入门 · 数据分析岗〕

    R² 是"被解释方差比例"，加变量只会增大或不变，可能虚高；调整 R² 对变量个数做了惩罚，变量没用时反而下降，更适合多变量模型比较。

    24. 线性回归和逻辑回归有什么区别？〔基础 · 通用必考〕

    线性回归预测连续值（如房价）；逻辑回归做分类，输出经 sigmoid 映射到 (0,1) 的概率。逻辑回归的损失是交叉熵，不是 MSE。

    25. 什么是损失函数？常用的有哪些？〔基础 · 大厂算法岗〕

    损失函数衡量"预测错的代价"。回归常用 MSE（均方误差）、MAE（绝对误差）；分类常用交叉熵（cross-entropy）。模型训练就是最小化损失函数。

    26. AIC 和 BIC 有什么区别？〔进阶 · 数据科学岗〕

    都是"模型复杂度惩罚"准则，值越小越好。AIC 惩罚较轻、适合预测/交叉验证；BIC 惩罚更重、更倾向选简单模型、适合估计"真实模型"；小样本推荐 AICc。

    四、分类：SVM 与决策树（对应第 3 周）¶

    27. SVM 的核心思想是什么？〔基础 · 大厂算法岗〕

    找一个"最大间隔"超平面把两类分开，离超平面最近的样本（支持向量）决定边界。目标是间隔越大、泛化越好。

    28. 什么是核技巧（kernel trick）？常用的核？〔进阶 · 大厂算法岗〕

    低维线性不可分时，通过核函数把数据隐式映射到高维，使其线性可分，而不用显式计算高维坐标。常用：线性核、多项式核、RBF（径向基，最常用）、Sigmoid 核。

    29. 决策树的原理是什么？〔基础 · 通用必考〕

    递归地选择"最能把数据分纯"的特征和切分点，把样本一层层划分，直到叶子节点。像一连串 if-else 规则。

    30. GINI 和熵（entropy）是什么？〔基础 · 大厂算法岗〕

    都是衡量"不纯度"的指标，值越小越纯（全是一类时 = 0）。GINI = 1 − Σp²；熵 = −Σ p·log₂p。决策树用它来选最优切分。

    31. 决策树的优缺点？〔基础 · 大厂算法岗〕

    优点：可解释、无需特征缩放、能处理非线性、对异常值稳健。缺点：容易过拟合、不稳定（对数据小变化敏感）、贪心切分可能非全局最优。

    32. 什么是信息增益？〔进阶 · 大厂算法岗〕

    用某特征切分后"不纯度下降了多少"（父节点熵 − 子节点加权熵）。信息增益越大，说明这个特征越能区分样本。信息增益比（gain ratio）会除以特征本身的熵，避免偏向取值多的特征。

    33. 决策树怎么防止过拟合？〔基础 · 大厂算法岗〕

    剪枝（预剪枝：限制深度/最少样本数/最少增益；后剪枝：建完再砍）、限制叶子节点数、用集成方法（随机森林）代替单棵树。

    34. 逻辑回归、决策树、SVM 怎么选？〔进阶 · 数据科学岗〕

    需要强可解释/概率输出 → 逻辑回归；特征复杂非线性、要直观规则 → 决策树；中小样本高维、追求分类边界 → SVM（RBF）；大数据、追求效果 → 直接用随机森林/XGBoost。

    五、集成方法（对应第 4 周）¶

    35. Bagging 和 Boosting 的区别？〔基础 · 通用必考〕

    Bagging：并行、有放回采样、模型独立，取平均/投票，降低方差（代表：随机森林）。Boosting：顺序、给错分样本加权、后一个修前一个，降低偏差（代表：XGBoost/AdaBoost）。

    36. 什么是随机森林？〔基础 · 通用必考〕

    基于 Bagging：有放回抽样生成多个子集，每个子集训一棵决策树，且每次切分只随机选一部分特征，最后投票/平均。随机性让树之间差异大，集成后更稳更准。

    37. 什么是袋外样本（OOB）？〔进阶 · 大厂算法岗〕

    Bagging 有放回抽样时，每次约 37%（约 1/3）样本没被抽中，这些"袋外"样本可当作免费验证集，用来估模型误差或特征重要性。

    38. 什么是 XGBoost？为什么它强？〔进阶 · 大厂算法岗〕

    梯度提升树的工程实现：正则化防过拟合、自动处理缺失值、支持并行、二阶导数加速、早停等。因其在 Kaggle 竞赛的统治力而出名。

    39. 随机森林和 XGBoost 怎么选？〔进阶 · 大厂算法岗〕

    小数据/要快速稳的基线 → 随机森林（少调参）；大数据/追求极致精度 → XGBoost（可调性强）。时间紧先上随机森林，有精力再上 XGBoost 调优。

    40. 什么是 AdaBoost？〔进阶 · 大厂算法岗〕

    自适应提升：每个弱学习器是"决策树桩"（只切一次），每轮提高上一轮分错样本的权重。缺点是怕噪声和异常值，大样本比 XGBoost 慢。

    41. 集成方法为什么能提升性能？〔进阶 · 大厂算法岗〕

    单个模型有偏差或方差，多个"多样且独立"的模型取平均/投票能相互抵消误差（大数定律）。前提是基模型要足够多样，否则"一群想得一样的人等于没想"。

    42. 什么是 Stacking？〔高级 · 大厂算法岗〕

    把多个不同模型的预测结果作为新特征，再训练一个元模型（meta-model）做最终预测，是"模型的集成"。比简单的投票/平均更灵活。

    六、模型评估¶

    43. 准确率、精确率、召回率有什么区别？〔基础 · 通用必考〕

    准确率 = 总正确率；精确率 = TP/(TP+FP)，"判为阳里有多少真阳"；召回率 = TP/(TP+FN)，"真阳里抓出多少"。类别不平衡时准确率会骗人。

    44. 什么是混淆矩阵？〔入门 · 通用必考〕

    2×2 表格：TP（真阳）、FP（假阳）、FN（假阴）、TN（真阴），是精确率/召回率/AUC 等指标的基础。

    45. 什么是 ROC 曲线和 AUC？〔基础 · 通用必考〕

    ROC 以假阳率（1−特异度）为横轴、真阳率（敏感度）为纵轴，随阈值变化画出曲线。AUC 是曲线下面积，0.5 是瞎猜、1 是完美，衡量模型"把正例排在负例前面"的整体能力，与阈值无关。

    46. 什么时候更看重精确率 vs 召回率？〔基础 · 数据分析岗〕

    看重精确率：误报代价高（垃圾邮件别误删、抓人别冤枉）。看重召回率：漏报代价高（癌症筛查、欺诈识别宁错不漏）。

    47. 类别不平衡怎么处理？〔进阶 · 大厂算法岗〕

    重采样（过采样/欠采样，如 SMOTE）、类别权重、换评估指标（用 AUC/F1 而非准确率）、用对不平衡更稳健的模型。

    48. F1 分数是什么？〔基础 · 通用必考〕

    精确率和召回率的调和平均：F1 = 2·P·R/(P+R)，两者都高时 F1 才高，适合不平衡数据下的单一指标。

    49. 什么是 SMOTE？〔进阶 · 大厂算法岗〕

    合成少数类过采样：在少数类样本之间插值生成新样本，比简单复制样本更能缓解过拟合，是处理不平衡的常用手段。

    七、特征工程与数据¶

    50. 缺失值怎么处理？〔入门 · 通用必考〕

    删（缺失太多）、填充（均值/中位数/众数/前后值）、用模型预测填充、或保留缺失并加"是否缺失"标志。树模型天然能处理缺失，XGBoost 内置。

    51. 标准化和归一化有什么区别？〔基础 · 大厂算法岗〕

    标准化（z-score）：减均值除标准差，结果服从均值 0 方差 1；归一化（min-max）：缩放到 [0,1]。对基于距离/梯度的模型（SVM、神经网络、正则化回归）通常必须做；树模型不需要。

    52. 分类变量怎么编码？〔基础 · 大厂算法岗〕

    One-hot（独热）：每个类别一列，适合无序类别、树/线性都可用，但类别多时会爆炸。Label（标签）：映射成整数，适合有序类别，但线性模型会把顺序当数值含义。

    53. 异常值怎么处理？〔基础 · 数据分析岗〕

    先识别（箱线图、3σ、孤立森林），再决定：删除、截断（winsorize）、变换（log）、或用对异常值稳健的模型（树模型）。不能无脑删，可能是有意义的事件。

    54. 特征选择有哪些方法？〔进阶 · 大厂算法岗〕

    过滤法（Filter，如方差、相关性）、包裹法（Wrapper，如递归消除 RFE）、嵌入法（Embedded，如 Lasso、树模型的特征重要性）。Lasso 是最省事的嵌入式选择。

    55. 什么是特征缩放？为什么重要？〔基础 · 大厂算法岗〕

    把不同量纲的特征拉到同一尺度。若不缩放，梯度下降收敛慢、距离类算法被大数值特征主导、正则化惩罚不公平。

    八、业务 / 场景题¶

    56. 给你一个「用户流失预测」任务，你会怎么做？〔进阶 · 数据科学岗〕

    按 CRISP-DM：业务理解（定义流失、定目标）→ 数据理解（行为/画像）→ 数据准备（清洗、特征工程、切分）→ 建模（先逻辑回归打基线，再上 XGBoost）→ 评估（AUC + 业务 ROI）→ 部署（打分 + 对高流失风险用户营销干预）。

    57. 为什么大样本下 p 值几乎必然显著？〔进阶 · 数据分析岗〕

    p 值依赖标准误，标准误 = σ/√n，n 越大标准误越小、统计量越大、p 越小。所以再小的真实差异，样本一多就"显著"——p 值被样本量绑架，这时更该看效应量。

    58. 怎么向非技术的人解释 AUC？〔入门 · 通用必考〕

    "AUC 是模型分辨好坏的能力：随机抽一个'好用户'和一个'坏用户'，模型把好用户排在前面概率。0.5 是瞎猜，0.9 是很会分辨。"

    59. 模型上线后效果变差（退化）怎么办？〔高级 · 大厂算法岗〕

    排查数据分布漂移（特征分布变了）、概念漂移（规律变了）、数据泄露/特征失效、标签质量问题；然后重训、监控 + 预警、做线上 A/B、必要时加自动化重训。

    60. 怎么判断一个模型能不能上线？〔进阶 · 大厂算法岗〕

    看四件事：① 离线指标（AUC/精确率/召回率）达标且经交叉验证稳定；② 业务收益（ROI）为正；③ 无数据泄露、特征都能在生产环境拿到；④ 有监控和回滚方案。上线后还要持续监控漂移。

    九、大模型与 LLM（近年高频）¶

    61. 什么是 Transformer？核心结构是什么？〔进阶 · 大厂算法岗〕

    基于自注意力机制，不依赖循环/卷积。由编码器-解码器堆叠而成，每层含多头自注意力 + 前馈网络 + 残差连接 + LayerNorm；用位置编码补充序列顺序信息。

    62. 什么是自注意力（self-attention）？Q/K/V 是什么？〔进阶 · 大厂算法岗〕

    每个 token 通过三组权重映射成 Query/Key/Value；用 Q·Kᵀ 算相似度得到注意力分数，softmax 归一化后加权求和 V，得到融合了全局上下文的表示。

    63. 什么是 RAG？为什么需要它？〔进阶 · 大厂算法岗〕

    检索增强生成：先从外部知识库（向量检索）召回相关文档，拼进提示词再让大模型生成。能缓解幻觉、让答案可溯源、无需重新训练即可接入私有知识。

    64. 什么是 LoRA？为什么能高效微调？〔进阶 · 大厂算法岗〕

    低秩适配：冻结原模型权重，只训练注入的低秩矩阵 ΔW=BA。可训练参数极少、显存小、即插即用，是当前主流的高效微调方案。

    65. 预训练、微调、提示工程有什么区别？〔基础 · 大厂算法岗〕

    预训练在超大规模语料上学通用能力；微调在下游数据上继续训练适配任务；提示工程不训练参数，只靠精心设计 prompt 引导模型输出。

    66. 什么是大模型「幻觉」？怎么缓解？〔进阶 · 大厂算法岗〕

    模型生成看似通顺但事实错误的内容。缓解：RAG 检索增强、要求引用来源、降低采样温度、明确"不知道就说不知道"、后处理事实校验。

    67. 什么是向量数据库？和传统数据库区别？〔基础 · 大厂算法岗〕

    专门存储向量并做近似最近邻（ANN）相似度检索，用于 embedding 语义搜索、RAG 召回。代表：Milvus、Pinecone、Weaviate。传统库按精确匹配/范围查询，向量库按语义相似度查询。

    68. 怎么评估一个大模型好不好？〔进阶 · 大厂算法岗〕

    分维度：通用能力（MMLU 等公开 benchmark）、业务任务指标（如 RAG 召回率/答案准确率）、人工评估、以及安全/幻觉率/成本/延迟。要多指标 + 人工抽检，不能只看榜单分数。

    十、深度学习基础¶

    69. 神经网络的前向传播和反向传播是什么？〔基础 · 大厂算法岗〕

    前向传播从输入逐层计算得到输出和损失；反向传播用链式法则把损失的梯度从输出层逐层回传到各参数，再用梯度下降更新权重。

    70. 常见激活函数有哪些？ReLU 为什么常用？〔基础 · 大厂算法岗〕

    Sigmoid、Tanh、ReLU、Leaky ReLU、GELU 等。ReLU=max(0,x)：计算快、正区间梯度恒为 1 能缓解梯度消失；缺点是负区间梯度为 0 产生"死神经元"，可用 Leaky ReLU 缓解。

    71. 什么是梯度消失和梯度爆炸？怎么解决？〔进阶 · 大厂算法岗〕

    深层网络反向传播时梯度逐层连乘，若每层都 <1 会指数衰减到 0（消失）、都 >1 会爆炸。解决：合理初始化、批归一化（BN）、残差连接、ReLU 类激活、梯度裁剪。

    72. SGD 和 Adam 的区别？〔进阶 · 大厂算法岗〕

    SGD 用固定或衰减学习率，收敛慢但泛化常更好；Adam 用一阶+二阶矩自适应调整学习率，收敛快、对超参不敏感，但有时泛化略差。工程上常用 AdamW。

    73. CNN 的核心思想？卷积和池化是干什么的？〔基础 · 大厂算法岗〕

    卷积核在输入上滑动提取局部特征（权重共享、平移不变）；池化（max/average）下采样降维、扩大感受野、增强鲁棒性。擅长图像等网格数据。

    74. RNN 和 LSTM 的区别？LSTM 解决了什么？〔进阶 · 大厂算法岗〕

    RNN 按时间步循环处理序列，但长期依赖下易梯度消失；LSTM 引入输入门/遗忘门/输出门和细胞状态，选择性记忆与遗忘，缓解长程依赖问题。

    75. dropout 和 batch normalization 分别是干什么的？〔基础 · 大厂算法岗〕

    dropout 训练时随机丢弃一部分神经元，降低神经元共适应、防过拟合（可看作隐式集成）；BN 对每个 mini-batch 归一化，加速收敛、稳定训练、允许更大学习率。

    76. 学习率太大或太小会怎样？〔入门 · 大厂算法岗〕

    太大：损失震荡甚至发散、无法收敛；太小：收敛极慢、易卡在局部最优。常用学习率调度（预热 + 衰减）或自适应优化器平衡。

    十一、公司真题精选（据公开面经整理的常见题型）¶

    说明

    以下按公司/岗位归类，是这些公司面试中的高频题型（非逐字真题，题型与考察点真实）。答案侧重思路与要点。

    77. 字节：推荐系统的召回和排序分别是什么？〔进阶 · 大厂算法岗〕〔二面〕

    召回从海量候选里快速筛出几百个可能感兴趣的（重效率，常用双塔/向量召回）；排序对召回结果精排打分（重精度）。完整漏斗：召回 → 粗排 → 精排 → 重排。

    78. 字节：怎么保证训练/推理时的特征一致性？〔高级 · 大厂算法岗〕〔三面〕

    线上线下特征口径不一致会导致线上退化。解决：统一特征平台、离线/在线特征同源落表、线上特征回放校验、监控特征分布漂移。

    79. 字节：用 SQL 求每个用户最近一次购买记录（窗口函数）。〔基础 · 数据分析岗〕〔一面〕 
    SELECT * FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY order_time DESC) AS rn
  FROM orders
) t WHERE rn = 1;
    80. 阿里：什么是辛普森悖论？和 AB 实验分流有什么关系？〔进阶 · 数据科学岗〕〔二面〕

    辛普森悖论：分组看是趋势 A，合并后反转为趋势 B（由混杂变量导致）。AB 实验要正确随机分流、检查各组基线一致，并同时看整体与分层结果，避免被混杂变量误导。

    81. 阿里：特征重要性怎么算？〔基础 · 大厂算法岗〕〔一面〕

    树模型：信息增益/分裂次数/节点杂质下降总量。模型无关方法：permutation importance（打乱某特征看性能下降多少）、SHAP（加性归因、更精确）。

    82. 阿里：怎么评估一次营销活动的增量效果？〔高级 · 数据科学岗〕〔三面〕

    不能只看活动后转化，要估计"没活动也会发生"的反事实。方法：随机 AB 实验、倾向得分匹配（PSM）、双重差分（DID）、因果森林等因果推断手段。

    83. 腾讯：用户留存分析怎么做（漏斗 / 同期群）？〔进阶 · 数据分析岗〕〔二面〕

    漏斗看各环节转化与流失点；同期群（cohort）按注册/首购时间分组，看不同批次用户的留存曲线，定位是哪个环节、哪批用户流失。

    84. 腾讯：社交/游戏里怎么做用户分群？〔进阶 · 数据科学岗〕〔二面〕

    选行为/画像特征 → 标准化 → 降维（PCA）→ 聚类（KMeans/层次/DBSCAN）→ 按群特征命名画像 → 精细化运营。注意聚类数选择与可解释性。

    85. 腾讯：怎么判断一个数据指标波动是正常的还是异常？〔进阶 · 数据分析岗〕〔一面〕

    看历史波动区间（均值±k倍标准差）、同比环比、是否节假日/活动/上线变更导致；再用异常检测算法（孤立森林/时序模型）辅助，结合业务判断。

    86. 美团：外卖配送时间（ETA）预测怎么建模？〔进阶 · 大厂算法岗〕〔二面〕

    特征：商家出餐、骑手位置、天气、时段、距离、路况等；用回归/树模型/XGBoost 预测，分城市/时段建模；损失可不对称（超时惩罚更高）。

    87. 美团：补贴是否带来增量订单？〔高级 · 数据科学岗〕〔三面〕

    做增量/归因分析：AB 实验对照，或用因果方法（PSM/DID）估计补贴的净增量，扣除"本来就会下单"的基数，算 ROI。

    88. 美团：模型线上效果衰减（退化）怎么办？〔进阶 · 大厂算法岗〕〔二面〕

    原因：数据/概念漂移、特征失效、负反馈循环。解决：持续监控漂移指标、定时重训、在线学习、A/B 回归、特征新鲜度治理。

    89. 百度：搜索里 CTR 预估怎么做？〔进阶 · 大厂算法岗〕〔二面〕

    预测点击率。经典：LR（稀疏特征）、FM（二阶交叉）、GBDT+LR；深度模型 DIN/DIEN 等。核心是海量稀疏特征工程 + 大规模训练。

    90. 百度：什么是知识图谱？实体对齐、链接预测是什么？〔进阶 · 大厂算法岗〕〔二面〕

    用「实体-关系-实体」三元组表示知识。链接预测=判断两个实体间可能存在什么关系；实体对齐=合并不同来源指向同一实体的节点。常用 TransE 等图嵌入建模。

    91. 华为：通信网络异常检测怎么做？〔进阶 · 大厂算法岗〕〔二面〕

    时序异常检测（告警突增、KPI 突降）、孤立森林/LSTM-AE 等无监督方法，结合规则阈值；关键要低误报、可解释、能定位根因。

    92. 华为：什么是模型压缩 / 知识蒸馏？〔进阶 · 大厂算法岗〕〔二面〕

    把大模型能力迁移到小模型用于端侧/边缘部署：知识蒸馏（大模型软标签教小模型）、剪枝、量化（降精度）、低秩分解。

    93. 外企（Google/Meta）：MAP@K 和 NDCG 是什么？〔进阶 · 大厂算法岗〕〔一面〕

    排序质量指标。MAP@K 看前 K 个结果相关性的平均精度；NDCG 对位置加权（越靠前权重越大）。都是搜索/推荐的核心排序指标。

    94. 外企（Google/Meta）：数据大到单机放不下怎么办？〔进阶 · 大厂算法岗〕〔二面〕

    分布式存储/计算（Spark/Hadoop）、分片、抽样、增量/流式训练、特征降维；模型侧用分布式训练框架或 GPU 集群。

    95. 外企：AB 测试的最小样本量怎么估算？〔进阶 · 数据科学岗〕〔二面〕

    由基线转化率、期望最小可检测效应（MDE）、显著性水平 α、统计功效 1−β 决定。MDE 越小、功效越高，所需样本越多；可用功效分析工具估算。

    96. 量化：量化策略里的过拟合长什么样？怎么防？〔高级 · 外企与量化〕〔三面〕

    回测反复调参导致"拟合历史噪声"，实盘失效。防：样本外测试、交叉验证、参数敏感性分析、计入交易成本/滑点、少参数、看稳健指标（夏普/回撤）。

    97. 量化：什么是夏普比率？回测有哪些陷阱？〔进阶 · 外企与量化〕〔二面〕

    夏普=(策略收益−无风险利率)/收益波动，衡量单位风险回报。回测陷阱：过拟合、未来函数（偷看未来数据）、忽略交易成本/滑点、幸存者偏差。

    98. 手撕：用 Python 手写线性回归的梯度下降。〔基础 · 大厂算法岗〕〔手撕〕 
    def gd_lr(X, y, lr=0.01, epochs=1000):
    n, d = X.shape
    w = np.zeros(d); b = 0.0
    for _ in range(epochs):
        pred = X @ w + b
        err = pred - y
        w -= lr * (X.T @ err) / n
        b -= lr * err.mean()
    return w, b
    99. 手撕：AUC 的计算思路是什么？〔进阶 · 大厂算法岗〕〔手撕〕

    AUC = 随机正样本排在随机负样本前面的概率。可按预测分排序，统计"正样本排在负样本前"的对子比例；或用"排序后正例的秩和"公式计算。

    100. 手撕：K-Means 聚类的思路是什么？〔基础 · 大厂算法岗〕〔手撕〕

    ①随机选 k 个中心；②每个点归到最近的中心；③更新中心为该簇均值；④重复②③直到中心不再变化。对初始点敏感，常用 k-means++ 初始化。

    101. 神经网络里的正则化（weight decay）是什么？〔基础 · 大厂算法岗〕

    在损失里加 L2 惩罚 ‖w‖²，等效于权重衰减，限制权重过大、防过拟合。AdamW 把它与自适应学习率正确解耦。

    102. 什么是早停（early stopping）？〔入门 · 大厂算法岗〕

    训练时监控验证集损失，连续若干轮不再下降就停止，取验证最优的模型，防止过拟合。

    103. 深度学习里类别不平衡怎么处理（focal loss）？〔进阶 · 大厂算法岗〕

    除重采样、类别权重外，focal loss 对"易分类样本"降权，让模型更关注难分样本，目标检测等极端不平衡场景常用。

    104. 什么是迁移学习？〔基础 · 大厂算法岗〕

    把在大数据上学到的预训练模型，迁移到小样本新任务上微调，省数据、收敛快。如 ImageNet 预训练 CNN 做下游分类。

    105. 什么是 embedding？word2vec 的原理？〔进阶 · 大厂算法岗〕

    把离散对象（词/用户/物品）映射成稠密向量，语义相近则向量相近。word2vec 用 CBOW/Skip-gram 在语料上学词向量，能捕捉"国王−男人+女人≈女王"这类语义关系。

    十二、进阶手撕题（高频，建议能手写）¶

    106. 手撕：逻辑回归的梯度下降（sigmoid + 交叉熵）。〔进阶 · 大厂算法岗〕〔手撕〕 
    import numpy as np
def sigmoid(z): return 1 / (1 + np.exp(-z))
def logistic_gd(X, y, lr=0.1, epochs=1000):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        p = sigmoid(X @ w + b)
        w -= lr * (X.T @ (p - y)) / n
        b -= lr * (p - y).mean()
    return w, b

    def softmax(x):

    def topk(nums, k):  # 返回最大的 k 个（不要求有序）
    def part(l, r):
        pivot, i = nums[r], l
        for j in range(l, r):
            if nums[j] > pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[r] = nums[r], nums[i]
        return i
    l, r = 0, len(nums) - 1
    while True:
        p = part(l, r)
        if p == k - 1: return nums[:k]
        elif p < k - 1: l = p + 1
        else: r = p - 1

    def auc(y_true, y_score):
    order = np.argsort(y_score)[::-1]       # 按分降序
    y = y_true[order]
    ranks = np.where(y == 1)[0] + 1         # 正样本秩（1-based）
    n_pos, n_neg = y.sum(), len(y) - y.sum()
    return (ranks.sum() - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)

    def gini(y):
    _, cnt = np.unique(y, return_counts=True)
    p = cnt / cnt.sum()
    return 1 - (p ** 2).sum()
def gain(y, left, right):
    n = len(y)
    g = gini(y) - (len(left) / n) * gini(left) - (len(right) / n) * gini(right)
    return g  # 越大说明切分越能提纯

    115. 手撕：IoU（交并比）计算。〔基础 · 大厂算法岗〕〔手撕〕 
    def iou(a, b):  # a,b = (x1,y1,x2,y2)
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    area_a = (a[2] - a[0]) * (a[3] - a[1])
    area_b = (b[2] - b[0]) * (b[3] - b[1])
    return inter / (area_a + area_b - inter)

    117. 手撕：用 numpy 实现二维卷积。〔进阶 · 大厂算法岗〕〔手撕〕 
    def conv2d(x, kernel):
    H, W = x.shape
    kh, kw = kernel.shape
    out = np.zeros((H - kh + 1, W - kw + 1))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = (x[i:i+kh, j:j+kw] * kernel).sum()
    return out
